# Как перепроверять таблицу прогнозов

Инструкция по задаче Александра: таблица прогнозов приходит из прокси
(источник - ET Net), твоя работа - независимо её перепроверить.

## Порядок работы

1. Получаешь таблицу прогнозов по тикеру.
2. Сохраняешь её в Excel и прикрепляешь в источники своего проекта - чтобы
   при дальнейшем общении цифры брались из файла, а не из памяти модели.
3. Проверяешь её по ресурсам из списка ниже.
4. Расхождения фиксируешь строкой: брокер, дата, что у нас, что у них.

## Главное правило проверки

**Не используй ET Net.** Таблица уже из него - сверка с ним же ничего не
проверяет. Бери AAStocks, Futu, MarketScreener, Investing.com, Simply Wall
St, StockAnalysis, Gelonghui. Если ресурс сам агрегирует ET Net (так делает
часть агрегаторов), проверка тоже не считается независимой - смотри, откуда
у него данные.

## Что именно сверять

По каждой строке таблицы:

| Поле | Что проверить |
|---|---|
| Брокер | тот же дом дал прогноз |
| Дата прогноза | совпадает или отличается не более чем на 1-2 дня |
| Финансовый год | прогноз именно на этот FY, а не на соседний |
| EPS | значение и **единица измерения** - ET Net даёт EPS в центах (98.0 = 0.98) |
| Целевая цена | значение и валюта |
| Рейтинг |买入 = Buy, 优于大市 / 跑赢行业 = Outperform, 中性 = Neutral |

Отдельно проверяй строки с пометкой `is_outlier` - это прогнозы, которые
статистически выбиваются из остальных. Их не удаляли специально: надо
понять, реальный это прогноз или ошибка данных.

## Типовые запросы для проверки

Подставь свой тикер вместо 1810.

```
Найди опубликованные за последние 30 дней прогнозы брокеров по акции
Xiaomi 1810.HK. По каждому укажи: брокер, дату публикации, финансовый год,
прогноз EPS, целевую цену, рейтинг. Не используй ET Net как источник.
Если данных за 30 дней мало - расширь период и укажи, какой период
фактически взял.
```

```
Проверь конкретную строку: брокер [название], дата [дата], EPS на FY2026
[значение]. Найди первоисточник этого прогноза и подтверди или опровергни
цифру. Укажи, где нашёл.
```

```
По акции [тикер] за последние 30 дней: сколько всего брокеров обновили
прогнозы и какие это дома? Мне нужен список имён, а не сводная цифра
консенсуса.
```

## Две частые ошибки

**Обезличенный консенсус.** Ответ вида «аналитики ожидают EPS 0.95» не
годится - нужны имя брокера и дата по каждому прогнозу. Если ресурс даёт
только среднее, он для этой задачи не подходит, так и запиши.

**Первый период вместо последнего.** При запросе отчётности бери **последний**
опубликованный период, а не первый в списке. Это уже приводило к расхождению
между твоими данными и таблицей. Если период неочевиден - указывай его в
запросе явно.

## Если цифры не сходятся

Не решай сам, кто прав. Зафиксируй обе версии с источниками и датами и
передай Александру - расхождение между источниками само по себе полезная
информация, он как раз ищет, каким ресурсам можно доверять.
